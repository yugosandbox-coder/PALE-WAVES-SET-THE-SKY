# PALE WAVES SET THE SKY

ブラウザで遊べるバレーボールゲームです。

## GitHub Pages での公開

1. このフォルダの中身（index.html / game.js / README.md）をリポジトリのいちばん上に置きます。
2. リポジトリの Settings → Pages を開きます。
3. Source を「Deploy from a branch」、Branch を main と / (root) にして Save します。
4. 数分たつと https://<ユーザー名>.github.io/<リポジトリ名>/ で遊べます。

- index.html と game.js は必ず同じ場所に置いてください。
- オンライン対戦は PeerJS の公開サーバーを使うので、サーバーの用意はいりません。
