移動：スティック・WASD・矢印キー（カメラの向きが前）。視点は右下のコンパスをドラッグ（Q / E）で回します（画面のドラッグでは回りません）。
コートは人数で大きさが変わり（2対2は10×20m、4対4は20×40m、6対6は30×60m）、周りをガラスの壁が囲んでいます。ボールは壁で跳ね返り、スパイクは壁に当たると速さの色が1段下がります。
ボールのタップ：近くに来たボールをタップすると、地上ならレシーブ／トス（立ったまま届かなければDIVE）、空中なら自分側のボールはスパイク（サーブ）のヒットストップ、相手側のボールはブロックになります。
トス/レシーブボタン（J）を押している間にボールが来るとレシーブします。レシーブは自分のコートのアタックラインより前のどこかへ上がります。2本目はトスのヒットストップ（1.5秒・自分の目線）になり、十字の先へ J でトス（横の距離＋高さ×2＝20m）。跳んでいる味方の頭の上の FAST でその人へ速いトス。壁で跳ね返ったトスは、トスした人も打てます。
ジャンプ（Space）はタップで小ジャンプ（1.5m・打点2.5〜5.5m）、0.5秒以上ためてから離すと大ジャンプ（ボタンの輪が満ちたら・6m・打点7〜10m）。トスは小さくジャンプして、その頂点で上げます（QUICKは5.5m、HIGH・BACKは10mまで上がるトス）。空中でスパイクボタン（K）を押すと打ちます。空中で壁に触れているときにジャンプを押すと壁ジャンプ。ブロック（L）は滞空時間が長めです。
キャラクタートス：J を押しっぱなしで待っている味方に、ジャンプして上から乗ると、乗った人が丸まり、待っていた人が十字の先へ J で投げ上げます（横の距離＋高さ×2＝16m、真上なら10m）。投げられた人は着地まで移動できず、スパイクとブロックだけ使えます。
DIVE（Shift）：近くのボールには飛び込みレシーブ、なければスティックの方向へ潜って移動。レシーブのときは、画面をスワイプするとその方向へDIVEします。能力ボタン（I）はサーブのときだけ出ます（フローター）。

    コーラル

      • ラリーポイント制。サーブ権を取り返したチームは時計回りに1つローテーションし、ゾーン1の選手がサーブ。交代はなく、全員がずっとコートに立ちます。
      • コートはトロピカルな浅い海。選手もボールもジェルでできていて、着地すると一瞬海に溶け、スパイクが決まると大きな水しぶきが上がります。
      • ポジションはありません。全員が同じ選手で、ローテーションの位置（前衛・後衛）だけが決まります。
      • ブロックで跳ぶと、止められる範囲がネットの上に長方形の壁として表示されます（色はその選手の体の色）。
      • 壁ジャンプ中やキャラクタートスで飛んでいる間に打つスパイクは、ルビーピンクの5倍速スパイクになります。
      • 反則になるプレー（4回目のタッチ、同じ選手の連続タッチ、5対5・6対6での後衛のブロックとアタックライン内からの後衛アタック）は、失点ではなく、そもそもできません。やろうとすると自分の画面に「〜はできない!!」と出ます。アンテナの外・アウト・サーブのネットは失点です。
      • スパイクの速さと色は打った高さで決まります（紺 → シアン → 水色 → 黄緑 → 黄 → オレンジ → えんじ → マゼンタ → ピンク）。高く跳んで打つほど速い。
